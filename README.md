This repository contains the implementation of a customer churn prediction model. The goal of the project is to predict whether customers will leave a service based on historical data, using various machine learning techniques.

Project Summary
Customer churn is a critical problem faced by companies in sectors like telecommunications and banking. This project applies machine learning to analyze customer behavior and predict churn, enabling businesses to take proactive measures to retain customers. The dataset used in this project includes customer information such as credit score, geography, gender, age, and account balance.

Key Features:
Data preprocessing: Handled missing data, encoded categorical features, and performed feature scaling to optimize model performance.
Model Selection: Evaluated multiple machine learning models including Logistic Regression, Decision Trees, Random Forest, and Gradient Boosting to predict churn.
Performance Evaluation: The models were compared using performance metrics such as accuracy, precision, recall, and F1 score to identify the best-performing algorithm.
Hyperparameter Tuning: Applied GridSearchCV to fine-tune the model's hyperparameters for optimal results.
Final Model: The Gradient Boosting model was selected as the final model based on its superior performance in predicting churn.
